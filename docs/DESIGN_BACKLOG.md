# DockWatch design backlog

> **What this file is:** gaps and judgment calls found while building the site against
> [`DESIGN.md`](DESIGN.md) v1.0, which is **frozen** until launch (F5). Each entry says what DESIGN.md doesn't
> cover (or where two parts disagree), what was built instead (the closest existing token or component), and what
> v1.1 should decide. Nothing here changes DESIGN.md; only accessibility failures may: one was found and fixed in
> DESIGN.md v1.0.1 (44 px touch targets in the List view; see its changelog). The remaining small targets (#35) were
> fixed on 2026-10-08 as implementations of §8, without a DESIGN.md change. Rows are never deleted; resolved ones say
> so.

**Last updated:** 2026-10-17 (F1, F2, F-1/F-2 fixes, DESIGN v1.0.1; paused state, Replay a day, #35 resolved, replay size budget; F3 alerts rail #46–#51, #34 / #39 / #44 updated; F4 Insights #52–#56; F4b Pipeline and F5 launch tests #57–#60; Loop L: #58 / #59 updated, the expectations card #61, a heatmap minimum-coverage proposal #62; Loop M: the lineage card #63; Loop M2: the nav overlay's opening fade #64; Loop N: the lineage card's full graph and Spark list #65)
