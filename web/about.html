About DockWatch

DockWatch shows which Bay Wheels stations are failing riders right now, with no bikes to take or no docks to return one, and how trustworthy the pipeline behind it is.

How it works

Every minute, a small producer reads the public Bay Wheels station feed (GBFS) and sends one message per station to Kafka. A Spark job turns those messages into Apache Iceberg tables, works out each station’s state (empty, low, ok, high, full or offline) and how long it has been in it, and raises an alert when a station stays empty or full. An exporter writes the latest state to the small JSON files this site reads.

DockWatch is a data engineering portfolio project. It is not an official service and may be paused at any time; every page says how old its data is.
